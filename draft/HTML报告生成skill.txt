# 任务：将资质模型分析报告转换为高级咨询风 HTML 页面

你是一名资深数据分析顾问 + 前端信息设计师。  
我会提供一份或多份 Markdown 格式的资质模型分析报告，请你将其整理并转换为一个**可直接打开的单文件 HTML 页面**。

## 一、整体目标

请把报告做成一个清晰、高级、咨询风的 HTML 页面，适合用于：
- 内部汇报；
- 模型评审；
- 策略讨论；
- 快速阅读。

页面需要兼顾：
- 信息结构清晰；
- 数据表格易读；
- 视觉风格高级；
- 重点结论突出；
- 原始数据完整保留。

## 二、内容处理要求

### 1. 保留原始报告核心内容

请完整保留我提供报告中的主要内容，包括但不限于：

- 报告概述；
- 模型基本信息；
- 样本设计与样本分布；
- 变量体系；
- 变量重要性；
- 变量 IV 表现；
- 模型方法与参数；
- 模型效果评估；
- 模型分箱表现；
- 风险模型 × 资质模型交叉分箱分析；
- 资质好 / 资质差 / 错配人群画像；
- 策略建议与后续使用建议。

注意：
- 不要随意改动原始数值；
- 不要擅自删除关键表格；
- 不要重新计算指标；
- 可以对表达做轻微润色，但不能改变业务含义。

---

### 2. 重构为咨询风报告结构

请将内容组织成更适合阅读的 HTML 报告结构，建议包含：

1. 封面区  
   - 报告标题；
   - 副标题；
   - 模型版本；
   - 报告定位；
   - 适用场景。

2. 模型速览  
   - 用 3-5 张结论卡片总结核心发现；
   - 每张卡片包含：
     - 结论标题；
     - 关键数据；
     - 业务含义。

3. 核心指标看板  
   - 展示样本量、目标率、AUC、KS、OOT 表现、Top/Bottom Lift 等核心指标；
   - 使用卡片化布局。

4. 主体分析章节  
   - 按原报告逻辑分章节展示；
   - 每章前面增加一句“本章要回答什么问题”；
   - 表格后可增加简短的业务解读。

5. 策略总结区  
   - 将“低风险+好资质”“高风险+差资质”“资质好但风险差”“资质差但风险好”等客群整理为策略矩阵；
   - 明确每类客群的：
     - 人群定义；
     - 数据表现；
     - 业务解释；
     - 建议动作。

6. 结尾区  
   - 总结模型价值；
   - 上线使用建议；
   - 后续校准、监控、策略验证建议。

## 三、视觉风格要求

整体风格要求：**高级、克制、清晰、咨询风、数据报告感强**。

### 1. 页面风格

请使用单文件 HTML，CSS 写在 `<style>` 中，不依赖外部资源。

视觉建议：

- 背景：浅灰、米白、淡蓝灰等高级底色；
- 主色：深蓝、墨蓝、蓝紫、青绿等专业色；
- 辅色：用于强调风险、资质、策略分层；
- 字体：使用系统字体，保证中文显示清晰；
- 页面宽度适中，适合浏览器阅读；
- 留白充分，不要拥挤；
- 卡片使用轻微阴影和圆角；
- 标题层级清楚。

---

### 2. 表格要求

表格是重点，请重点优化。

所有表格需要：

- 表头使用渐变色；
- 表格整体有圆角、阴影或边框；
- 数值列右对齐；
- 百分比、金额、样本数保持清晰格式；
- 行 hover 时有高亮效果；
- Total / 合计 行需要特殊底色强调；
- 重要指标可使用浅色热力底色，例如：
  - 风险指标高：浅红；
  - 资质/收入/通过率高：浅绿或浅蓝；
  - 中性指标：浅灰或浅蓝。

如果表格很宽：
- 支持横向滚动；
- 表格外层加 `.table-wrap`；
- 不要让页面整体撑爆。

---

### 3. 重点内容呈现

请将关键结论做成更醒目的视觉模块：

- 结论卡片；
- 指标卡片；
- 策略矩阵；
- 风险提示框；
- 业务解释框；
- 分割线和章节编号。

示例风格：

- “结论一：资质模型具备风险模型之外的增量区分能力”
- “低风险 + 好资质：优先经营”
- “高风险 + 差资质：优先控制”
- “资质好但风险差：收入强但波动高，需要谨慎经营”
- “资质差但风险好：收入弱但行为保守，可低额度验证”

1. 左侧固定目录导航  
   - 自动列出主要章节；

2. 页面顶部摘要

4. 表格可滚动

   - 增加简单 `@media print` 样式；
   - 打印时隐藏目录或弱化阴影。

## 五、内容表达风格

请使用以下表达风格：

- 理性；
- 克制；
- 客观；
- 咨询报告风；
- 不夸张；
- 不口号化；
- 重点突出“数据证据 → 业务解释 → 策略动作”。

避免：
- 过度营销化表达；
- 空泛形容词；
- 没有数据支撑的结论；
- 只基于单个格子的片面判断。

所有核心结论尽量遵循：

> 先给结论，再给数据证据，再解释业务含义，最后给策略建议。
